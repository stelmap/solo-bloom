# Групи: повний функціонал за специфікацією

Розширюємо наявні сторінки «Групи», «Деталі групи» та «Супервізії» і чинний Календар — без заміни календаря, без нових платежів і без зміни тарифів. Усі наявні групи, учасники, відвідуваність та оплати зберігаються.

## Етапи

1. **Налаштування групи (G-01, G-08)**
   - Тип: звичайна / супервізійна; інструкція для учасників; ліміт місць; ціна; правило оплати пропуску (замінює чинні позначки «рахувати відсутніх»).
   - Архівація та «видалення» лише як позначка — історія, зустрічі й оплати лишаються. Майбутні зустрічі видаленої групи в календарі показуються як скасовані.
   - «Копіювати групу» — копіює лише налаштування, не минулі зустрічі/оплати.

2. **Публікація та заявки (G-02, G-03)**
   - Публічна сторінка реєстрації за непередбачуваним посиланням; неопублікована — недоступна.
   - Форма: ім'я, email, телефон (необов'язково). Відвідувач не бачить інших учасників.
   - Вкладка «Заявки»: підтвердити / відхилити / в список очікування. При заповненому ліміті нові заявки йдуть у список очікування.
   - Прив'язка до клієнта лише за точним email; інакше створюється новий клієнт — без злиття за схожим ім'ям.
   - Перенесення вибраних зі списку очікування в наявну або нову скопійовану групу; стара заявка лишається в історії.

3. **Зустрічі, відвідуваність, оплати (G-04–G-06)**
   - Одноразові та повторювані зустрічі через чинний механізм календаря; ціна конкретної зустрічі може відрізнятися.
   - Присутність кожного учасника; для супервізій — «активна робота / спостерігач», що не впливає на суму.
   - Сума до оплати за правилом пропуску; скасована зустріч нічого не нараховує. Терапевт вручну відмічає «отримано» — через чинний облік оплат учасників, без онлайн-платежів.

4. **Повідомлення та матеріали (G-07)**
   - Листи: заявку отримано, підтверджено, відхилено, список очікування, зміна розкладу, матеріали.
   - Файли матеріалів не вкладаються в лист (поштова система цього не підтримує) — у листі буде посилання на завантаження.
   - Лише учасникам цієї групи, по одному листу кожному.

5. **Переклади та перевірка**
   - Усі нові тексти шістьма мовами (uk/en/pl/de/fr/ru), «Зустріч» замість «Сесія».
   - Тести на правила: ліміт/список очікування, оплата пропуску, скасована зустріч, супервізійна активність не змінює суму, приватність публічної сторінки.

## Технічні деталі
- Міграції: нові поля в `groups` (тип, інструкція, capacity, price, absence policy, publication/lifecycle status, registration_token, copied_from_group_id, archived_at/deleted_at); нова таблиця `group_registrations`; поля `registration_id/left_at` у `group_members`; `supervision_participation` у `group_attendance`. GRANT + RLS лише власнику.
- Публічні читання та подача заявки — тільки через SECURITY DEFINER RPC за токеном (як у бронюванні), з обмеженням частоти.
- Чинні `bill_absent` переносяться у нове правило без втрати значень.
- Листи — через наявну систему app emails (нові шаблони в реєстрі).
- Ліміт Pro (якщо вже є) не змінюється.

Виконую поетапно; після кожного етапу — перевірка в браузері на тестовому акаунті.
